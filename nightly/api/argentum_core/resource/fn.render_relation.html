Expand description

Render rows as a titled, read-only table (GH #187).

rows is the related records the record already carries — the caller passes record.comments.get().iter().cloned().collect() or the equivalent — so this runs no query. An empty set renders the title with an honest “none” line rather than an empty table, which would read as a failure to load.

The rows are rendered in the order given; a detail page shows what the query loaded, and Resource::query owns that order.
