Panel — the admin application shell.

Owns the [Router] and the Db in app_context, and registers each declared Resource’s list page at {prefix}/{slug} (Filament-style routes — ADR-0008). See CONTEXT.md.

Layout: Panel builder + route table live here; shell rendering in shell, list + live shard support in list, form decoding and create/edit in forms, the record detail page in detail, delete/bulk/export in actions, the live-search registry + shard dispatch in search, and response hardening headers in headers.
