Notification — transient user-visible message (CONTEXT.md).

Produced by an Action’s result and rendered in the Panel shell’s top-level boundary so it survives Table swaps. Status + title (plus an optional description), auto-dismissed after ~4s by argentum-ui/assets/notifications.js and dismissible through the toast’s close button — the shadcn/Sonner toast surface (GH #151).

The flash cookie is Topcoat’s CookieStore (serde JSON, GH #139); the jar defaults carry the hardened attributes (HttpOnly, Secure, SameSite=Lax, Path=/ — the __Host- name requires them, GH #149) on writes and removals alike, so set and clear cannot drift. One-time semantics ride the cookie alone: Topcoat flushes Set-Cookie on error responses too (topcoat#408), so the mutation Err redirects carry the flash in the cookie alone.
