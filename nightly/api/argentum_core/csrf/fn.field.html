pub fn field<'a>(cx: &'a Cx, token: &str) -> BoxView<'a>
Expand description

The hidden field every state-changing form embeds.

The token is passed in, never resolved here: whether a site calls ensure_token (which sets the cookie and must run before response headers are sent) or current_token (the only one safe inside a streamed suspense child) is the site’s decision, and a helper that guessed would either panic after header send or silently embed nothing. What the helper owns is the spelling — FIELD_NAME is what verify reads, so a rename that missed a form would be a silent 403 on every POST.
