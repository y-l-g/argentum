Toast — the shadcn/Sonner surface, owned by Argentum.

The parts mirror shadcn’s Sonner composition: a toaster stack, the toast surface, toast_icon, toast_content with toast_title / toast_description, and toast_close. The classes follow shadcn’s new-york Sonner theming (bg-background text-foreground border-border shadow-lg, description text-muted-foreground) over Sonner’s own layout values (356px stack, 16px padding, 13px text, 14px gap, 20px circular close button, bottom-right offset).

The enter/exit motion is Sonner’s: the server renders data-mounted="false" (slid down, transparent), notifications.js flips it to data-mounted="true" to play the transition, and flips data-removed="true" before removing the toast. A <noscript> rule keeps toasts visible without JS, where auto-dismissal and the close button only work by navigation.
