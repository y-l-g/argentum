The app’s Lucide icons, resolved once from the staged icon set.

iconify_icon! resolves against the compiling crate’s staged sets (ADR-0007 stages Lucide in this crate’s build script), so the consts live here and argentum-core renders them with icon instead of staging a second copy of the set.
