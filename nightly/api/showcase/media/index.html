Module media 

Source
Expand description

The media library: the medias table, the page that fills it, and the widget that previews a file before it is stored.

A media row is a stored file plus a polymorphic owner: owner_type and owner_id name a Post or a User, and no foreign key can hold that pair together (ADR-0021). The page uploads through the app’s own Uploader — the DirUploader the panel installs for FileUpload — writes the row, and lists what the library holds: a thumbnail for an image, a link for anything else.

Post::media is a different thing and keeps its name: the embedded enum holding an image/video description in the post’s own columns. This page stores files; that value describes one. CONTEXT.md keeps the two apart.
