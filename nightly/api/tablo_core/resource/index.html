Resource — maps one Toasty Model to its admin UI.

One Model → one Resource. The trait is the single seam for query scoping (query), form/table stubs, and navigation. See CONTEXT.md and ADR-0002.

Facade over the cohesive submodules split out in GH #133: filter, column, state, table (+ table::render/table::export), navigation, and naming. The re-export surface is unchanged.
